知识库设置三个角色:

- 知识库管理员(admin)：

  - 全局管理权限（用户权限控制页)
  - 知识库: 可查看所有部门文件，可下载，可上传（任意部门)
- 可编辑的成员

  - 知识库编辑权限: 可上传
  - 知识库查看权限：仅能查看/下载自己部门的文件
- 普通用户

  - 只读： 可列出/下载自己部门的文件
  - 不可上传、不可进权限控制





### 部门scope

每个知识库文件都带一个 `dept_key`，比如 `AI`, `micro_service`

每个用户带一个“可访问部门列表”：

- allowed_dept_keys: list[str]

对任何 KB 文件资源（list/detail/download/search）：

- 如果用户是 **admin** → **允许访问所有 dept**
- 否则 → **仅允许访问 `dept_key ∈ allowed_dept_keys` 的文件**
