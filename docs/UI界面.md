登录注册页面

对于未登录的用户，会自动弹出登录页面，保持现有的登录页面即可



提问页面

- 页面左边侧边栏展示用户所能访问的知识库文件内容，用户可以根据权限，点击查看

- 页面下方有提问窗口，可以搜索知识库内容，向大模型提问

- 页面上方Tab页

  - 展示用于头像

  - 对于管理员用户，新增一个按钮，点击之后跳转到权限控制页面

  - 对于具有可编辑权限的用户，添加一个+号的按钮，点击之后弹出一个列表(目前仅包含"上传pdf"), 用户点击之后可以上传pdf

     

权限控制页面

- 页面下方展示系统中所有用户的信息，包括：

  - 姓名

  - 用户名

  - 权限分配
    - 权限分配有两个选项：查看，编辑

- 页面上方有一个搜索搜索栏，可以按照用户名进行搜索
