                                    │ N:1
                                    ▼

                                    ▼

| 表名             | 说明                | 核心字段                                              |
| ---------------- | ------------------- | ----------------------------------------------------- |
| users            | 用户表              | id, username, password_hash, is_active                |
| roles            | 角色定义表          | id, role_key (admin/editor/viewer), name, description |
| permissions      | 权限点表            | id, perm_key (kb:file:list等), name, description      |
| departments      | 部门表              | id, dept_key, name, description                       |
| user_roles       | 用户角色关联        | user_id, role_id                                      |
| role_permissions | 角色权限关联        | role_id, permission_id                                |
| user_departments | 用户部门关联 (ABAC) | user_id, department_id, can_read, can_write           |
