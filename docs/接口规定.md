### 一、认证接口 (auth_router)
需要 JWT 认证，用于用户登录和身份管理：

1. **POST /auth/login** - 用户登录
   - 验证用户名和密码
   - 生成 JWT token 并设置到 cookie

2. **POST /auth/logout** - 用户登出
   - 清除 cookie 中的 token

3. **GET /auth/me** - 获取当前用户信息
   - 返回已登录用户的身份信息（user_id、roles、dept_key 等）

---

### 二、公开接口 (public_router)
无需认证，可公开访问：

1. **GET /info** - 获取服务元数据
   - 返回可用的 agents 列表
   - 返回可用的 models 列表
   - 返回默认 agent 和默认 model

2. **GET /health** - 健康检查
   - 检查服务状态
   - 检查 Langfuse 连接状态（如果启用）

---

### 三、受保护接口 (protected_router)
需要用户登录认证：

1. **POST /invoke 或 /{agent_id}/invoke** - 调用 Agent
   - 发送用户消息给指定 agent
   - 返回完整的响应（非流式）
   - 支持多轮对话（通过 thread_id）
   - 支持 agent 中断恢复
   - 支持 Langfuse 追踪

2. **POST /stream 或 /{agent_id}/stream** - 流式调用 Agent
   - 使用 SSE (Server-Sent Events) 流式返回响应
   - 可选择是否流式返回 token（stream_tokens 参数）
   - 支持中间步骤消息和最终响应
   - 支持多轮对话和中断恢复

3. **POST /feedback** - 提交反馈
   - 向 LangSmith 提交对某次运行的反馈
   - 用于质量评估和模型优化

4. **POST /history** - 获取聊天历史
   - 根据 thread_id 获取对话历史
   - 返回历史消息列表

---

### 四、知识库接口 (kb_router)
需要用户登录认证，基于文件权限控制：

1. **GET /kb/files** - 列出知识库文件
   - 支持按文件名搜索（q 参数）
   - 支持按部门筛选（dept_key 参数）
   - 支持分页（cursor、limit 参数）
   - 只返回当前用户有权限查看的文件
   - 仅支持 PDF 类型文件
   - 根据用户权限标记 can_view、can_edit

2. **GET /kb/files/{file_id}** - 获取文件详情
   - 返回文件的详细信息
   - 包含文件页数（page_count）
   - 包含权限标记
   - 无权限或文件不存在时返回 404

3. **GET /kb/files/{file_id}/download** - 下载文件
   - 以附件形式下载 PDF 文件
   - 支持 UTF-8 编码的文件名
   - 仅限有下载权限的用户访问
