### 知识库接口

- `GET /kb/files`

  列出用户可见文件



- `GET /kb/files/{file_id}`

  获取单个文件元信息

  - response

    ```json
    {
      "file_id": "f_123",
      "name": "员工手册.pdf",
      "type": "pdf",
      "dept_key": "AI",
      "page_count": 42,
      "updated_at": "2026-01-05T10:00:00Z",
      "can_view": true,
      "can_edit": false
    }
    ```



- `GET /kb/files/{file_id}/download`

- `GET /kb/files/{file_id}/pages/{page}/image`

  逐页渲染



- `POST /kb/files/upload`

  上传PDF, 只有edit权限可用
